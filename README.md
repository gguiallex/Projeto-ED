Dados de Evento dos Atletas em crescente utilizando Merge MultiWay

Sobre

Este projeto em C++ permite manipular registros de atletas armazenados em um arquivo binário. Os dados vêm de um arquivo CSV e são convertidos automaticamente. O usuário pode inserir, alterar, visualizar, trocar e ordenar os registros pelo campo "Esporte".

A ordenação é feita por meio do algoritmo Merge Multiway, eficiente para grandes volumes de dados.

---

Como compilar

No terminal, execute:
make run

---

Estrutura

main: interface principal
registro: define o formato dos registros
manipuladorBinario: lida com o arquivo binário
minHeap: usado na ordenação
